# Panggilan Monse UI Direction

Direction source: the product's existing TTS workflow and the owner's request for a UI that is simple and easy to use.

- Identity: a practical announcement console for sending text or recorded audio to connected master devices.
- Personality: calm, direct, dependable, and friendly without decorative noise.
- Palette: warm neutral canvas, dark ink for legibility, teal for the primary action, and amber only for attention or master status.
- Typography: the system sans-serif stack keeps Indonesian interface text familiar, fast, and readable on shared devices.
- Mood: operational clarity. The current task and connection state should be understood at a glance.
- Theme: light-only because this is an operational control surface likely used in shared, well-lit spaces; strong contrast is prioritized over mood.
- Dial: ENERGY 1 / RHYTHM 1 / MOTION 1.

## Decision reasons

- Color: teal separates the main send action from neutral secondary controls without looking like a generic technology gradient.
- Layout: the message composer is the widest region because composing and sending is the screen's primary job.
- Typography: one system type family reduces loading dependencies and keeps dense controls easy to scan.
- Spacing: a compact 4/8px-based scale supports frequent operational use while preserving clear section boundaries.
- Cards: flat bordered surfaces group tasks; only the sticky action panel receives elevation because it must remain visually available.
- Icons: icons are used only when they reinforce a known action or state, always alongside a text label.
- Motion: short state transitions provide feedback; decorative loops and entrance choreography are omitted.
